    A["anh Thức nêu yêu cầu"] --> B{"Loại công việc?"}

    B -->|"Lỗi production / UAT"| D["Luồng H — Hotfix"]

Luồng HHotfix — sửa lỗi gấp

Vá đúng một lỗi, gộp về 1 cổng GATE-HOTFIX; Sev1/chạm dữ liệu bắt buộc rà bảo mật delta.

flowchart TD
    H0["H0 · PO: Tiếp nhận & phân loại Sev1-4"] --> H1["H1 · Dev + Tester: Reproduce & root cause"]
    H1 --> H2["H2 · Dev: Vá tối thiểu + regression test"]
    H2 --> H3["H3 · Tester: Smoke + regression"]
    H3 --> SEC{"Chạm auth / dữ liệu hoặc Sev1?"}
    SEC -->|"Có"| HSEC["H-SEC · Security: rà bảo mật delta"]
    SEC -->|"Không"| GATE
    HSEC --> GATE{{"GATE-HOTFIX · anh Thức duyệt"}}
    GATE -->|"Cần sửa"| H2
    GATE -->|"Duyệt"| H4["H4 · DevOps: Deploy + smoke test"]
    H4 -->|"Nếu production"| R["Sang Luồng R (từ R3)"]
    H4 --> H5["H5 · PO: Cập nhật tài liệu + post-mortem"]

Luồng CChange Request — thay đổi nhỏ

Chỉ làm phần delta, giữ truy vết; 2 cổng CR-1 (chốt phạm vi) và CR-2 (nghiệm thu).

flowchart TD
    C1["C1 · PO: Tiếp nhận CR"] --> C2["C2 · BA + SA: Phân tích tác động"]
    C2 --> G1{{"GATE-CR-1 · anh Thức chốt phạm vi"}}
    G1 -->|"Không làm / Hoãn"| STOP["Đóng hoặc hoãn CR"]
    G1 -->|"Duyệt"| C3["C3 · SA + Designer: Cập nhật thiết kế (chỉ delta)"]
    C3 --> C4["C4 · Dev đến Tester: Code + test delta & regression"]
    C4 --> CSEC{"Chạm bảo mật?"}
    CSEC -->|"Có"| SEC["C-SEC · Security: rà delta"]
    CSEC -->|"Không"| G2
    SEC --> G2{{"GATE-CR-2 · anh Thức nghiệm thu"}}
    G2 -->|"Cần sửa"| C3
    G2 -->|"Duyệt"| C5["C5 · DevOps: Phát hành"]
    C5 -->|"Nếu production"| R["Sang Luồng R"]

Luồng RRelease — lên production

Không hoàn tác: bắt buộc GATE-RELEASE + backup + rollback; xác nhận cuối trước khi deploy.

flowchart TD
    R1["R1 · DevOps: version, release-notes, rollback, backup"] --> R2["R2 · PO: Rà Go / No-Go"]
    R2 --> GR{{"GATE-RELEASE · anh Thức duyệt (KHÔNG HOÀN TÁC)"}}
    GR -->|"No-Go"| FIX["Quay lại xử lý"]
    GR -->|"Go"| R3["R3: Chốt cửa sổ + xác nhận cuối + backup"]
    R3 --> R4["R4 · DevOps: Deploy production + smoke test"]
    R4 --> CHK{"Đạt tiêu chí?"}
    CHK -->|"Không"| RB["Rollback theo kế hoạch"]
    CHK -->|"Có"| R5["R5: Theo dõi sau phát hành"]
    RB --> R6["R6 · PO: Đóng phát hành + thông báo"]
    R5 --> GRD{{"GATE-RELEASE-DONE · anh Thức xác nhận"}}
    GRD --> R6
